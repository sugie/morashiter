# 名称候補と選定基準

## 選定基準

- 被害者を「原告」「クレーマー」と決めつけない
- 訴訟・受任・補償を保証する印象を与えない
- 日本語でも英語でも発音しやすい
- 個人情報漏えい以外の多数消費者被害にも拡張できる
- アプリ名、ドメイン、商標の衝突が少ない

## 候補

| 候補 | 意味 | 強み | 注意点 |
|---|---|---|---|
| RightsRelay | 権利と意思を支援主体へ中継する | 役割が明確。英語展開可能 | `Rights` がやや硬い |
| KOE Relay | 小さな声を束ねて届ける | 親しみやすい | 海外で意味の説明が必要 |
| RightGather | 権利・当事者を集める | 集約機能が伝わる | 英語として造語感がある |
| Redress Commons | 被害回復の共有基盤 | 公共性と専門性が高い | 一般利用者には難しい |
| KOETABA / 声束 | 声を束ねる | 独自性が高い | 法律・被害回復との関係が弱い |
| JoinCase | 案件への参加 | 操作が直感的 | 訴訟参加と誤解されやすい |
| morashiter | 意味・表記意図は未整理 | 2026-10-01に名称候補として検討 | 読み・表記・商標・ドメインは未確認 |

## 現在の作業名

**RightsRelay / ライツリレー（仮称）**

タグライン: **小さな被害を、動かせる力に。**

2026-09-30の一次調査では、J-PlatPatの完全一致・称呼検索は0件だった。一方、同名ソフトウェアと登録済みの `rightsrelay.com` が見つかったため、正式名称としての確定は保留する。Gate Aまでは作業名として使い、第一バックアップを **KOETABA / 声束** とする。詳細は[名称クリアランス一次調査](name-clearance.md)を参照。
