# 支援主体向け評価セッション手順 v1

## 目的

弁護士、特定適格消費者団体、消費生活相談員等に、RightsRelayの支援主体向け試作を評価してもらい、Gate Aの継続判断に必要な証拠を得る。

主に検証する仮説は次の三つ。

- H2: 構造化された受付情報は、初期整理の時間・重複確認を減らす
- H3: 法律判断をRightsRelayが行わない役割分担が成立する
- H4: 証拠原本を中央保管しなくても、案件の初期トリアージに価値を出せる

## 対象者と最低サンプル

- 個人情報漏えいまたは消費者事件を扱う弁護士 2人以上
- 特定適格消費者団体の被害回復業務担当 2組織以上
- 可能なら消費生活相談員または情報管理担当 1人以上
- 合計5セッションを第1ラウンドとする

同一組織の複数人を別組織として数えない。

## 使用するもの

- 非公開の支援主体向けレビュー画面
- 画面内の「架空サンプル5件」
- [最小共有パケット仕様](./share-packet-spec.md)
- [法的境界メモ](./legal-boundary-memo.md)
- [脅威モデル](./threat-model.md)
- 試作から書き出す `rightsrelay-support-evaluation.json`
- [Gate A 判定キット](./gate-a-scorecard.md)

実在する被害者、相談者、事件記録、通知メール、証拠原本は使用しない。

## 事前説明

次を口頭と画面で説明する。

- 試作は法律相談、事件紹介、正式受付、委任、授権、訴訟参加ではない
- 画面は架空データだけで評価する
- 氏名、組織名、連絡先、自由記述を評価JSONに含めない
- 回答は法律意見、提携合意、実証参加の確約ではない
- 引用・団体名公表・録音は、別途明示同意がない限り行わない

## 45分の進行

| 時間 | 内容 |
|---:|---|
| 0〜5分 | 目的、非目的、記録範囲を説明 |
| 5〜15分 | 現在の初期受付フロー、所要時間、重複確認を質問 |
| 15〜25分 | 架空サンプル5件を読み込み、支援主体向け画面を操作してもらう |
| 25〜35分 | 画面内の10問へ本人が回答し、評価JSONを書き出す |
| 35〜42分 | 必須項目、法的境界、原本受領時期、運用上の懸念を確認 |
| 42〜45分 | 修正版評価または小規模実証への協力可能性を確認 |

## 操作タスク

1. 「架空サンプル5件で試す」を押す
2. 集計から、案件を検討するために何が分かるか説明する
3. 「この集計だけでは判断できないこと」を確認する
4. 集計結果だけを書き出す
5. 「支援主体評価を開始する」を押す
6. 10問へ回答し、識別子なしの評価結果を書き出す

進行役は、ボタンの場所が見つからない場合を除き操作方法を教えない。

## 観察項目

- 集計値の意味を正しく説明できたか
- パケット数を被害者本人の実数と誤認したか
- 「対象の可能性」を請求権・制度対象と誤認したか
- 読込みファイルがサーバー保存されると誤認したか
- 正式受付に必要な追加項目を具体的に指摘できたか
- 証拠原本が必要になる段階を説明できたか
- 現行業務に組み込む具体的な場面を示したか
- 修正版評価または小規模実証への具体的な協力意思を示したか

## 評価JSONに含めるもの

- 立場の区分
- 現在の初期整理時間帯
- 初期トリアージ価値の有無
- 試作利用時の予想時間帯
- 最低限追加したい項目のカテゴリ
- 最大の懸念カテゴリ
- 希望する受取形式
- 法律相談・正式受付との境界評価
- 次の協力可能性
- 証拠原本をRightsRelayへ渡す必要がある段階
- 回答所要時間

氏名、連絡先、所属組織、自由記述、実在案件、共有パケットは含めない。

## Gate Aの判定規則

第1ラウンド5セッション終了後、次の順で判定する。

### 継続

すべて満たす場合。

1. 弁護士2人以上、特定適格消費者団体2組織以上を含む
2. 5人中2人以上が「そのまま価値がある」または「修正すれば価値がある」と回答
3. 5人中1人以上が修正版評価または小規模実証を検討できると回答
4. 現在時間を把握している回答者のうち、2人以上で予想時間帯が短くなる
5. 「重大な誤認リスクがある」が0件、または指摘事項を修正して再評価済み
6. 高機密原本を初期段階からRightsRelayへ集中保管することを必須とする回答が過半数でない

### 条件付き継続

価値は確認できたが、境界表示、項目、形式、運用の重大な修正が必要な場合。修正後に別の対象者3人以上で再評価する。

### 方向転換

次のいずれかに該当する場合。

- 5人中4人以上が「この形では価値がない」
- 初期整理時間が短くなる具体的根拠が得られない
- 原本の事前集中保管なしには価値がないとの回答が過半数
- 法律判断・周旋をRightsRelayが担わなければ中核価値が成立しない

### 停止

弁護士レビューで、現行の中核フロー自体が重大な法的リスクを避けられないと判断された場合。表示修正だけで解決できないときは実データ実証へ進まない。

## 記録方法

- 対象者には `L-001`、`O-001` 等の調査用IDを付ける
- JSONと観察メモは別ファイルにする
- 発言事実と観察者の解釈を分ける
- 組織名を出してよい同意がない限り、仮説台帳には区分だけを書く
- 相反する評価も削除せず残す
- 5セッション終了まで、重大な安全問題以外の画面変更を入れない
- 5件の評価JSONは[Gate A 判定キット](./gate-a-scorecard.md)で検証・集計し、手動確認が `null` のままなら継続判定にしない
