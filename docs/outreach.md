# ヒアリング候補と依頼文

更新日: 2026-09-30

外部への連絡はまだ行っていない。この文書は送信候補と草案であり、送信前に内容、差出人名、所属、返信先を確認する。

## 特定適格消費者団体

消費者庁の2026年8月末時点の一覧では、特定適格消費者団体は次の4団体。

| 団体 | 公開窓口 | 本プロジェクトで聞きたいこと |
|---|---|---|
| 消費者機構日本 | [被害情報の提供](https://www.coj.gr.jp/provide/) | 現行フォームの受付・分類負担、情報提供と正式な被害回復手続の境界 |
| 消費者支援機構関西 | [情報提供窓口](https://www.kc-s.or.jp/accept) | 必須項目、追加確認が多い項目、支援システムからの受入形式 |
| 埼玉消費者被害をなくす会 | [公式サイト](https://saitama-higainakusukai.or.jp/) | 少人数組織での大量情報受付、地域外事案の連携方法 |
| 消費者支援ネット北海道 | [公式サイト](https://e-hocnet.info/) | 既存の被害者登録フォーム運用、参加意思と授権の分離 |

認定状態と連絡先は、送信直前に[消費者庁の一覧](https://www.caa.go.jp/policies/policy/consumer_system/collective_litigation_system/about_qualified_consumer_organization/list_of_specified)で再確認する。

## 団体向け依頼文案

件名: 集団的消費者被害の初期受付支援に関するヒアリングのお願い

本文:

> 突然のご連絡失礼いたします。  
> 個人情報漏えいなど、多数の消費者に同種の被害が生じる事案について、被害者が対象条件・証拠保有状況・参加意思を整理し、本人の同意の下で特定適格消費者団体や弁護士へ情報提供できる仕組みを検討しています。現在は企画検証段階で、法律相談、弁護士紹介、訴訟参加の受付は行っていません。  
>  
> システムを先に作るのではなく、実際の被害回復業務における初期受付・情報整理の負担と、第三者が支援できる範囲を理解したく、オンラインで45分程度お話を伺えないでしょうか。個別事件についての見解や法律相談をお願いする趣旨ではありません。  
>  
> 主に、(1) 初期受付で必要な情報、(2) 被害者への追加確認が多い項目、(3) 参加意思と正式な授権の区別、(4) 安全に情報提供を受ける条件、(5) 外部ツールが関与すべきでない領域について伺いたいと考えています。  
>  
> ヒアリング内容は、事前に確認した範囲を除き、団体名や個人名と結び付けて公表しません。録音も原則行いません。ご検討いただけましたら幸いです。

## 法律家向け依頼文案

件名: 個人情報漏えい被害の受付基盤に関する法的境界ヒアリングのお願い

本文:

> 個人情報漏えい等の多数消費者被害について、被害者の参加意思と証拠保有状況を安全に整理し、弁護士または特定適格消費者団体が案件化を検討しやすくする受付基盤を企画しています。  
>  
> 現在はDiscovery段階であり、法律相談、事件の評価、弁護士紹介、受任・授権、成果連動課金は行わない前提です。この切り分けが実務上・法的に成立するか、45分程度のヒアリングでご意見を伺いたくご連絡しました。  
>  
> とくに、弁護士法72条上の法律事務・周旋との境界、対象可能性チェックの表現、外部提供同意、証拠原本の扱いについて確認したいと考えています。正式な法律意見書が必要な段階では、別途、有償での依頼を相談させてください。

## 被害経験者向け募集文案

> 企業から「個人情報が漏えいした、または漏えいした可能性がある」という通知を受け取った経験について、30分程度お話を伺える方を募集しています。  
>  
> 企業名、氏名、会員番号、漏えいした情報の原本をお知らせいただく必要はありません。補償案内や法律相談ではなく、通知を受けた後に何が分かりにくかったか、どんな行動に時間がかかったかを調べるためのヒアリングです。録音は原則行わず、公表する場合も事前に確認した、個人を直接特定しない集計情報に限ります。

実際の募集・選考は[被害経験者テストの募集・スクリーニング](participant-recruitment.md)を使用し、連絡先と調査結果を分離する。

- [ ] 相手の活動を事前に確認し、依頼理由を一文追加した
- [ ] 録音、引用、成果物公開の扱いを明記した
- [ ] 資格・認定・連絡先を送信当日に再確認した
- [ ] 一斉送信せず、一団体ずつ送った
