# プロジェクト憲章

更新日: 2026-09-30

## 1. 問題

個人情報漏えいは一度に多数の人へ影響する一方、一人当たりの回復可能額は小さくなりやすい。被害者は、事件の理解、対象確認、証拠保全、相談先の探索を個別に行わなければならない。支援側も、多数の問い合わせを同じ形式へ整理する負担を負う。

RightsRelay は、個々の法律判断を自動化するのではなく、共通する事実と参加意思を、支援主体が検討できる形へ整える。

## 2. 対象利用者

### 第1利用者

- 企業から漏えい通知を受け取った人
- 退会済みで、対象か判断できない人
- 実害は未確認だが、本人確認書類など高リスク情報が漏えいした人

### 第2利用者

- 個人情報・消費者事件を扱う弁護士、弁護団
- 特定適格消費者団体
- 消費生活相談員など、公的・公益的な支援者

## 3. 価値提案

### 被害者へ

「ニュースを読む」から「自分の状況を整理し、安全に意思表示する」までを一つの導線にする。

### 支援主体へ

問い合わせの重複処理を減らし、共通事実、人数、証拠保有状況、同意状態を検討可能な形式で受け取れるようにする。

## 4. 成功指標

### Discovery

- 被害経験者10人以上のうち、7人以上が現在の対応方法に迷った経験を語る
- 法律家・団体5者以上のうち、2者以上が構造化された受付情報に実務価値を認める
- 少なくとも1者がプロトタイプ評価に継続参加する

### Prototype

- 「対象可能性確認」「証拠チェック作成」「参加意向登録」の完了率80%以上
- タスク完了時間中央値10分以内
- 誤解テストで、90%以上が「登録は訴訟参加や受任ではない」と理解する
- 高機密情報をサーバーへ送らずに主要フローを完了できる

### Pilot

- 支援主体側の初期受付・分類時間を、従来比30%以上削減する
- 同意のない情報移転が0件
- 重大なセキュリティ事故0件
- 削除請求の完了率100%

## 5. 非目標

- AIによる勝訴可能性・慰謝料額の判定
- 自動法律相談、代理交渉、示談の仲介
- 被害者情報の販売または広告ターゲティング
- 参加人数を使った企業への威圧
- 企業の責任が確定する前の断定的な非難
- 漏えいした本人確認書類の中央保管

## 6. 原則

1. **Collect less** — 集めないことを最優先の安全対策とする。
2. **Consent is specific** — 参加意向、連絡許可、外部提供を別々に同意する。
3. **Human legal judgment** — 法的判断は資格と責任を持つ人・団体が行う。
4. **Evidence before claims** — 公式発表と確認済み事実を、推測や評価から分離する。
5. **Free path to relief** — 救済に必要な基本導線を有料化しない。
6. **Exit is real** — 利用者は参加撤回、データ書き出し、削除を容易に行える。

## 7. 意思決定ゲート

### Gate A — 2026年11月末

継続条件: 支援主体が受付コストの問題を確認し、解決案に実務価値を認める。

### Gate B — 2027年3月末

継続条件: 利用者が誤解なく主要フローを完了し、現行手段より明確に有用である。

### Gate C — 2027年5月末

継続条件: 法務・セキュリティ上の重大な未解決事項がなく、小規模実証の受け手がいる。

いずれかを満たさない場合は、機能縮小、対象変更、または停止を選択する。
