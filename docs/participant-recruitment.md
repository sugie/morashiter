# 被害経験者テストの募集・スクリーニング

## 目的

漏えい通知を受けた経験のある成人を、実在事件の詳細や高機密情報を集めずに募集する。これは法律相談、被害申告、補償申請、訴訟参加者募集ではない。

## 募集文

> 企業から「個人情報が漏えいした、または漏えいした可能性がある」という通知を受け取った経験のある18歳以上の方を対象に、30分程度のオンライン画面テストを行います。  
>  
> テストでは架空の状況を使います。企業名、氏名、会員番号、通知メール、本人確認書類、カード情報、実際の被害内容を提出・入力する必要はありません。法律相談、補償案内、被害申告、訴訟参加の受付ではありません。  
>  
> 録音は原則行いません。調査記録には `V-001` のような番号を使い、画面から書き出す結果には氏名・連絡先・実在案件の情報を含めません。参加は途中で中止でき、謝礼の有無に影響させません。

謝礼を設定する場合は、金額、受取条件、支払方法、税務上の扱いを募集公開前に確定し、この文章へ追記する。「被害に対する補償」と受け取られる表現をしない。

## 最小スクリーナー

回答は選択式とし、企業名や事件名を尋ねない。

1. 18歳以上ですか: `はい / いいえ`
2. 企業・団体から、個人情報漏えいまたはその可能性を知らせる通知を受け取った経験がありますか: `はい / いいえ / 回答しない`
3. 通知時点のサービスとの関係: `利用中 / 退会・利用終了後 / 申込み途中 / その他・不明 / 回答しない`
4. 通知後に、不審連絡、カード再発行、費用負担などの対応が必要になりましたか: `はい / いいえ / 判断できない / 回答しない`
5. 30分間、パソコンまたはスマートフォンの画面を共有せずに試作を操作できますか: `はい / いいえ`
6. 法律相談、補償判断、個別事件の調査ではないことを理解しましたか: `はい / いいえ`

選考に使わない情報を「念のため」に尋ねない。自由記述欄、ファイル添付、通知メール転送欄、企業名欄、住所欄、電話番号欄は設けない。

## 適格条件

- 18歳以上
- 漏えい通知を受け取った経験がある
- 調査の非法律相談・架空シナリオ利用を理解している
- 30分の操作テストに参加できる

除外理由は `under-18 / no-notice-experience / unavailable / purpose-not-understood` のカテゴリだけで残し、回答内容の詳細を保存しない。

## サンプルの割付

各段階で可能な範囲で次の片寄りを避ける。

- 通知時点で利用中／利用終了後
- 追加対応あり／なし
- パソコン／スマートフォン

これは統計的代表性を主張する標本ではない。特定の属性だけで成功した結果を全被害者へ一般化しない。

## 募集経路

優先順は次のとおり。

1. 知人ネットワークへの個別依頼。ただし参加を断りにくい上下関係を避ける
2. 消費者・プライバシー分野のコミュニティ管理者へ、募集掲載の許可を得る
3. 支援主体からの紹介。本人がRightsRelayへ直接連絡し、紹介者へ参加有無を返さない
4. 公開募集。企業名や特定事件名を広告見出しに使って不安を煽らない

企業の被害情報受付窓口、消費者団体の個別相談窓口、SNS上の被害者個人へ無差別に勧誘しない。

## 日程調整時の禁止事項

- 実際の通知メールを返信・転送してもらわない
- 本人確認書類や被害明細を送ってもらわない
- 「対象者か確認します」「補償につなげます」と約束しない
- 個別事件の法律相談を受けない
- 紹介者へ、誰が参加したかを知らせない

参加希望者が実在データを送ってきた場合、内容を調査記録へ転記せず、削除可能なら削除し、架空シナリオだけを使うことを再説明する。

## セッション開始時の確認文

進行役は次を読み上げ、すべて確認してから開始する。

> 今日は画面の分かりやすさを調べます。あなたの事件や判断を評価するものではありません。実際の企業名、会員番号、通知メール、本人確認書類、被害内容は話したり入力したりしないでください。法律相談、補償案内、正式な被害申告、委任、訴訟参加にはなりません。途中で理由を言わず中止できます。録音はしません。結果は調査用番号で記録し、氏名・連絡先とは分けます。この条件で参加しますか。

回答は `同意 / 不同意` と日時・同意文バージョンだけを連絡先管理側へ記録する。不同意なら開始しない。

## セッション終了時

- 実在情報を記録していないことを参加者と確認する
- プライベートブラウズ画面を閉じる
- 撤回期限と連絡方法を案内する
- 調査用IDを本人へ知らせる必要はない。撤回照合は連絡先管理側だけで行う
- 法律相談を求められた場合は調査を終了し、特定の専門家を恣意的に紹介しない

連絡先・同意・匿名IDの分離と削除期限は[調査データ取扱手順](research-data-protocol.md)に従う。
