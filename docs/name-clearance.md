# 名称クリアランス一次調査

調査日: 2026-09-30  
対象: **RightsRelay / ライツリレー**  
結論: **黄 — 作業名として継続可。公開ブランドとしての確定は保留。**

この文書は企画段階の簡易調査であり、商標の登録可能性・侵害の有無に関する法的意見ではない。

## 結果

| 観点 | 確認結果 | 判断 |
|---|---|---|
| 国内商標・商標文字 | J-PlatPatの「商標（検索用）」で `RightsRelay` と `ライツリレー` を完全一致検索し、いずれも0件 | 明白な完全一致は見つからなかった。ただし未掲載出願や検索条件による漏れを否定しない |
| 国内商標・称呼 | `ライツリレー` の称呼単純文字列検索・称呼類似検索はいずれも0件 | 一次スクリーニング上は明白な一致なし。専門家による再検索が必要 |
| 構成語 | `Rights Relay` を空白区切りで検索するとOR検索となり19件。第9・42・45類を含む `RELAY` / `Rights` の登録例が表示された | `RELAY` は混雑しており、構成語単体の独占性は期待しにくい |
| 同名ソフトウェア | GitHubに `Wang4F/rightsrelay` があり、合成音声メディアの権利・失効管理パイプラインとして2026年8月に更新されている | 用途は異なるが、ソフトウェア名の完全一致として無視できない |
| アプリストア | Apple App Store / Google Playを対象とする公開ウェブ検索では、完全一致の掲載を確認できなかった | ストア内検索・対象国別検索を公開前に再実施する。不存在の証明ではない |
| `.com` | Verisign RDAPで `rightsrelay.com` の登録を確認。登録日は2026-04-20、レジストラはNameCheap | 取得不可を前提にする。譲受交渉は現段階では行わない |
| `.jp` | JPRS WHOISで `rightsrelay.jp` は `No match` | 調査時点では登録情報なし。ただし状態は変わり得る |
| 日本語表記 | 一般ウェブ検索で `ライツリレー` の明白な同名サービスを確認できなかった | 国内向け表示には使いやすいが、英字ブランドとの一体性は残る |

## 判定

RightsRelayは役割を説明しやすく、面談や試作の呼称としては引き続き有用である。一方、次の理由から正式ブランドとしてロックしない。

1. 同名の公開ソフトウェアが存在する
2. `.com` が第三者に登録されている
3. `RELAY` が第9・42・45類を含め広く使われている
4. J-PlatPatの0件は登録可能性や非侵害を保証しない

## 当面の運用

- Gate Aの支援主体ヒアリングまでは **RightsRelay（仮称）** と表記する
- ロゴ、法人名、ストア掲載名、広告費、商標出願にはまだ固定投資しない
- 公開パイロットの4週間前までに、弁理士または知財に詳しい弁護士へ第9・42・45類を中心とした検索を依頼する
- `rightsrelay.com` へのリンクやメールアドレスを使わない
- ドメイン・SNS名は取得可能性だけでなく、なりすましリスクを含めて公開前に再確認する

## 代替名

第一バックアップは **KOETABA / 声束（こえたば）** とする。

- J-PlatPatで `KOETABA`、`声束`、称呼 `コエタバ` は一次検索0件
- `koetaba.com` はVerisign RDAPで404、`koetaba.jp` はJPRS WHOISで `No match`
- 一般ウェブ検索ではインドネシアのコーヒー商標 `KOETABA COFFEE` が見つかるため、世界的な完全独占を前提にしない
- 独自性は比較的高いが、被害回復サービスであることはタグラインや説明文で補う必要がある

## 正式決定の条件

次をすべて満たすまで名称を確定しない。

- 弁理士等による類似商標検索と指定商品・役務の整理
- 日本のApp Store / Google Play内での完全一致・類似検索
- `.jp`、代替ドメイン、主要SNSアカウントの再確認
- 支援主体3者以上、被害経験者5人以上による誤認・発音テスト
- 法律相談、弁護士紹介、補償保証を想起させないことの法務確認
