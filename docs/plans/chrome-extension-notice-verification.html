Chrome 拡張「登録店舗のページでお知らせを出す」検証計画

作成 2026-11-08 ／ 対象：ローカルのブランチ feat/chrome-extension-mvp（884cfe0, 73486b8。push しない）／ 状態：計画（未実施）／ PayPal AI Hackathon 応募の準備

結論
  • 今の拡張は、登録したホストのページを開くと、アイコンを押さなくてもツールバーのアイコンにバッジ（事故の件数）が付き、アイコンを押すと詳しい内容がポップアップに出る作りです。まず、これが Windows の Chrome で動くことを確かめます。
  • 照合はホスト単位なので、店舗のどのページ（商品ページも）でも同じお知らせが出ます。ただし、今のテストページにはトップページしかありません。商品ページでの確認は、まず存在しないパス（404 のページ）で代わりに確かめ、必要ならテストページに商品ページを足します（判断2）。
  • データは架空の店舗だけで、ホストは *.localhost（このパソコン自身）です。実在のサイトでは何も出ません。外部への通信もしません。

2. 決めてほしいこと

判断1：「お知らせ」は何を指すか

案見え方必要な変更注意
A. バッジ＋ポップアップ（今の作り）アイコンに件数が付き、押すと内容が出るなしアイコンをツールバーに固定（ピン留め）しないと気付きにくい
B. デスクトップ通知を足すWindows の通知が右下に出るnotifications 権限、同じ店舗で何度も出さない工夫、テストうるさくなりやすい。審査員の環境で通知が切られていることもある
C. ページの中に帯を出す店舗のページの上部に帯が出るコンテンツスクリプトとホストの権限「ページを書き換えない」という今の方針と、計画書の範囲（ページの書き換えは含めない）に反する。権限の説明も重くなる

推奨：A。今回の検証は A で行います。B は、A が動いたあとに、動画で目立たせたい場合だけ検討します。

判断2：商品ページをテストページに足すか

  • 推奨：まずは足さずに、http://aozora-zakka.localhost:8765/products/mug-01 のような存在しないパス（404 のページ）で、お知らせが出ることを確かめます。ホスト単位の照合なので、これで「商品ページでも出る」ことを確かめられます。
  • 動画やデモで見せるために本物らしい商品ページが要る場合は、test-site/products/ に架空の商品ページを足し、serve-test-site.mjs で配信するようにします。これはローカルのブランチを変えることになるので、お手元の未コミットの変更を確かめてから、了承を得て行います。
ハッカソンで見せる完成形（計画書の merchant-index.json を読み込む方式、デモ店舗 /demo-shop、PayPal の案内）は、まだ作っていません。この検証は、その前に土台（タブを監視してお知らせを出す部分）が Windows の Chrome で動くことを確かめるためのものです。

3. 守ること

  • 拡張のブランチは push しません。マージ、デプロイ、Chrome ウェブストアへの公開もしません。
  • お手元の未コミットの変更は、勝手に破棄・退避・コミットしません。
  • 外部のライブラリ、CDN、外部との通信は使いません。実在の企業に架空の事故を結び付けません。
  • 手順は一度に1つずつ案内し、結果を返していただいてから次に進みます。実施していない確認を、確認済みとは書きません。

5. うまくいかないとき

症状考えられる原因対応
*.localhost のページが開けないWindows の Chrome が *.localhost をこのパソコンに向けていない、またはプロキシやセキュリティソフトの設定まず http://localhost:8765/ が開けるか確かめます（ページは開けますが、照合の対象外のホストなのでバッジは出ません）。開ける場合は、Chrome の設定またはプロキシの例外が原因なので、結果を見て対応を相談します。hosts ファイルの変更（管理者権限が必要）は、了承を得てから行います。
ページは開くがバッジが出ない拡張が古い、サービスワーカーが止まっている、ピン留めしていない拡張の更新ボタン → タブを F5 → Service Worker の Console を確認
ポップアップが「確認中」のままサービスワーカーのエラーService Worker の Console のエラーをそのまま貼ってください
テストページのサーバーが起動しないポート 8765 が使用中、Node.js が古いnode tools/serve-test-site.mjs 8766 のように別のポートで起動

どのページでも動かない場合でも、デモシナリオ（ポップアップの「このタブで表示」）なら任意のページで画面を見られます。ただし、これは自動照合の確認にはなりません。
